FSAgent Configuration Builder

Visueller Konfigurations-Generator mit Blockly
Generierte Konfiguration
Klicken Sie auf "Generieren" um die JSON-Konfiguration zu erstellen. Ziehen Sie FSAgent-Blöcke aus der Toolbox in den Workspace und konfigurieren Sie Ihre Automatisierung.
Schnellanleitung

1. Ziehen Sie "FSAgent Job" Blöcke in den Workspace

2. Konfigurieren Sie Trigger (Dateievents, Timer, HTTP)

3. Fügen Sie Aktionen hinzu (Copy, Move, HTTP, etc.)

4. Verbinden Sie Success/Failure Flows

5. Generieren und laden Sie die config.json herunter

FSAgent Configuration Builder Hilfe

🚀 Schnellstart

  1. Ziehen Sie einen "FSAgent Job" Block in den Workspace
  2. Konfigurieren Sie den Ordnerpfad und Pattern
  3. Fügen Sie einen Trigger hinzu (Dateievents, Timer, HTTP)
  4. Verbinden Sie Aktionen für die Dateiverarbeitung
  5. Generieren und laden Sie die JSON-Konfiguration herunter

📁 Verfügbare Module

  • 🤖 OpenAI: KI-gestützte Dateianalyse
  • 📢 Notifications: Slack, Discord, Teams Benachrichtigungen
  • 🗄️ Database: SQLite, MySQL, PostgreSQL Operationen
  • 🔧 File Processing: Hash, Metadaten, Duplikat-Erkennung
  • 📂 FTP/SFTP: Sicherer Dateitransfer

💡 Tipps

  • Verwenden Sie Success/Failure Flows für robuste Workflows
  • Auto-Save speichert Ihre Arbeit automatisch
  • Nutzen Sie Platzhalter wie $file, $filepath, $timestamp
  • Testen Sie Konfigurationen mit kleinen Dateien zuerst
